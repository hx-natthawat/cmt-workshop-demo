# Lab 1 · Agent-Readiness Audit — ตรวจแบรนด์จริงด้วย Claude

Session 3 (Agent Economy) · Part 1 Discover · 30 นาที · ทีม 3-4 ท่าน
มองแบรนด์ด้วย "ตา Agent" แล้วให้คะแนน 4 ประตูที่ทำให้ agent มองเห็นแบรนด์

## ขั้นตอน (worksheet ต่อทีม)

- **Step 1 (5 นาที)** — เลือกแบรนด์: ของทีมเอง หรือแบรนด์ไทยที่รู้จักดี
- **Step 2 (15 นาที)** — ใช้ Claude เป็น "agent จำลอง" (prompt starter ด้านล่าง) ให้ค้นเว็บจริงแล้วตอบ: สินค้าหลักราคาเท่าไร มีของไหม ส่งกี่วัน คืนสินค้าอย่างไร มีโปรโมชันอะไร
- **Step 3 (5 นาที)** — ให้คะแนน 4 ประตู ประตูละ 0-5 (ตารางด้านล่าง)
- **Step 4 (5 นาที)** — สรุป 1 ประโยค: "สิ่งแรกที่ต้องแก้คือ ______" แล้วแชร์หน้าห้อง

## Prompt Starter (แทน [สินค้า] และ [ชื่อแบรนด์])

> คุณคือ shopping agent ที่ลูกค้าสั่งให้ซื้อ **[สินค้า]** จากแบรนด์ **[ชื่อแบรนด์]** ค้นเว็บจริงแล้วรายงาน: ข้อมูลใดหาเจอ/หาไม่เจอ ราคา สต็อก เงื่อนไขส่ง-คืน และสรุปว่าถ้าท่านเป็น agent จะกล้าสั่งซื้อจากแบรนด์นี้หรือไม่ เพราะอะไร

## Worksheet — ให้คะแนน 4 ประตู (ประตูละ 0-5)

| # | ประตู | ดูอะไร | คะแนน 0-5 | สิ่งที่ต้องแก้ |
|---|---|---|:---:|---|
| 1 | **Structured Data บนเว็บ** | Schema.org (Product/Offer/FAQ), ราคา/สต็อกเป็นข้อความจริง ไม่ฝังในภาพ | | |
| 2 | **เนื้อหาสำหรับ Answer Engines (AEO)** | คำตอบชัด อ้างอิงได้ เป็นกลางพอที่ AI หยิบไปตอบ + ไฟล์แนะนำ AI เช่น `llms.txt` | | |
| 3 | **MCP Server ของแบรนด์** | มี "หน้าร้านสาขา agent" เปิดแคตตาล็อก/สต็อก/โปรให้ AI เรียกตรงอย่างมีสิทธิ์ควบคุมไหม | | |
| 4 | **Agent Card (A2A)** | "นามบัตรมาตรฐาน" ประกาศว่า agent แบรนด์ทำ/เจรจาอะไรได้ ติดต่อทางไหน | | |
| | | **รวม / 20** | | |

> ลำดับใหม่ของ funnel: ก่อนชนะใจลูกค้า ต้องผ่านการคัดกรองของ agent ที่ลูกค้าไว้ใจก่อน
> ขั้น 1-2 เริ่มได้สัปดาห์นี้ งบแทบเป็นศูนย์ · ขั้น 3 = สิ่งที่สร้างใน Advanced MCP แล้ว

## สิ่งที่มักค้นพบ (ใช้ชี้ประเด็นหน้าห้อง)

- ราคาซ่อนใน LINE/DM — agent อ่านไม่ได้
- โปรโมชันอยู่ในรูปภาพ — agent มองไม่เห็น
- นโยบายคืนสินค้าไม่มีเป็นลายลักษณ์อักษร
